# لعبة بناء المدن - نسخة أندرويد (Flutter)

نفس فكرة النسخة الويب، لكن كتطبيق أندرويد حقيقي بلغة Dart/Flutter، فوق خريطة
حقيقية (OpenStreetMap عبر حزمة `flutter_map`)، مع وضعين للعب:

- **فردي** — نفس تجربة النسخة الويب، حفظ محلي على الجهاز.
- **جماعي تنافسي** — من 2 إلى 5 لاعبين، كل واحد يبني مدينته الخاصة، وتظهر
  لوحة صدارة حية (نقاط لحظية) طول الجولة عبر Firebase. الفائز من يجمع أعلى
  نقاط عند انتهاء الوقت.

## المتطلبات

- Flutter SDK (تم بناء المشروع واختباره على 3.47.0 stable)
- Android SDK + جهاز/محاكي أندرويد لتشغيل التطبيق فعليًا
- حساب Firebase مجاني (فقط لتفعيل وضع "لعب جماعي")

> **ملاحظة مهمة**: هذا المشروع طُوّر واختُبر داخل بيئة سحابية بدون Android SDK
> مثبّت، فتم التحقق منه بـ `flutter analyze` (بدون أي أخطاء) و `flutter test`
> (اختبار الواجهة الرئيسية ناجح) فقط — لم يُبنَ APK فعلي هناك. ابنِ التطبيق على
> جهازك (فيه Android Studio/Android SDK) أو عبر CI للتأكد من التشغيل الكامل
> على جهاز حقيقي.

## الإعداد

### 1) تثبيت الحزم

```bash
cd mobile
flutter pub get
```

### 2) تفعيل اللعب الجماعي (Firebase) — اختياري لكن مطلوب لوضع "لعب جماعي"

اللعب الفردي يشتغل بدون أي إعداد إضافي. لتفعيل اللعب الجماعي:

1. أنشئ مشروع على [console.firebase.google.com](https://console.firebase.google.com)
2. من قسم **Build → Firestore Database**، أنشئ قاعدة بيانات (ابدأ بوضع
   "test mode" للتجربة السريعة بين الأصدقاء).
3. ثبّت أداة FlutterFire وفعّلها لمشروعك:
   ```bash
   dart pub global activate flutterfire_cli
   cd mobile
   flutterfire configure
   ```
   اختر مشروع Firebase الذي أنشأته، وحدد منصة **Android** فقط. هذا يستبدل
   `lib/firebase_options.dart` (حاليًا فيه قيم placeholder) بقيم مشروعك الحقيقية.
4. (اختياري لكن مستحسن) انشر قواعد الأمان الموجودة في `firestore.rules`:
   ```bash
   firebase deploy --only firestore:rules
   ```
   القواعد الحالية بسيطة ومفتوحة لأي شخص يعرف رمز الغرفة (كافية للعب بين
   أصدقاء) — راجع التعليق أعلى الملف قبل أي إطلاق أوسع.

### 3) التشغيل

```bash
flutter run   # على جهاز/محاكي متصل
```

### 4) بناء APK للتوزيع

```bash
flutter build apk --release
# الناتج في: build/app/outputs/flutter-apk/app-release.apk
```

## آلية اللعب الجماعي

- المضيف يُنشئ غرفة (يختار المدينة ومدة الجولة)، ويحصل على **رمز غرفة** من 5
  أحرف يشاركه مع بقية اللاعبين (2 إلى 5).
- كل لاعب يضغط "انضمام" ويدخل الرمز.
- عند بدء الجولة، كل لاعب يبني في **نسخته الخاصة** من نفس المدينة (المباني
  غير مشتركة/مرئية بين اللاعبين، فقط الأرقام).
- كل جهاز يشغّل محاكاة اللعبة محليًا (نفس منطق اللعب الفردي)، ويرسل إحصاءاته
  (الذهب، السكان، النقاط) لـ Firestore كل ثانيتين تقريبًا.
- الجميع يشاهدون **لوحة صدارة حية** فوق الخريطة تتحدث لحظيًا.
- عند انتهاء الوقت، تظهر النتيجة النهائية والفائز (الأعلى نقاطًا).
- معادلة النقاط: `النقاط = الذهب + (السكان × 20)`.

## البنية

```
lib/
  main.dart                          نقطة الدخول + تهيئة Firebase
  firebase_options.dart              placeholder يستبدله flutterfire configure
  models/
    building.dart                     أنواع المباني وتكلفتها وتأثيرها
    city.dart                         إحداثيات الرياض وبريدة
    player_city_state.dart            منطق الحالة والمحاكاة (مطابق game.js بالويب)
  services/
    local_save_service.dart           حفظ اللعب الفردي محليًا (SharedPreferences)
    multiplayer_service.dart          غرف Firestore، المزامنة، لوحة الصدارة
  widgets/
    city_map.dart                     الخريطة (flutter_map) + طبقة المباني
    building_palette.dart             قائمة اختيار المباني
    stats_bar.dart                    شريط الموارد
  screens/
    home_screen.dart                  الشاشة الرئيسية
    singleplayer_game_screen.dart     شاشة اللعب الفردي
    multiplayer_lobby_screen.dart     إنشاء/الانضمام لغرفة
    multiplayer_room_screen.dart      الانتظار + اللعب التنافسي + النتيجة
firestore.rules                       قواعد أمان أولية لقاعدة بيانات الغرف
```

## أفكار للتطوير لاحقًا

- Firebase Authentication (حتى Anonymous) بدل الاعتماد فقط على رمز الغرفة.
- دردشة نصية داخل الغرفة، أو أحداث تنافسية (غارة على مدينة لاعب آخر).
- دعم iOS (المشروع أُنشئ بمنصة أندرويد فقط حسب الطلب، لكن flutter_map/Firestore
  يدعمان iOS أيضًا لو احتجتها لاحقًا).
- إشعارات عند بدء/انتهاء الجولة حتى لو التطبيق بالخلفية.
