# مسابقة (Masabaqa)

تطبيق جوال (Flutter) لمسابقات أسئلة، فيه ٤ طرق لعب:

1. **مجموعة - الأسرع يفوز**: يدخل الكل غرفة واحدة، وأول من يجاوب صح على كل
   سؤال ياخذ أعلى نقاط (١٠)، والي بعده أقل، وهكذا.
2. **مجموعة - سباق الوقت**: كل من يجاوب صح قبل انتهاء وقت السؤال (١٥ ثانية)
   ياخذ النقاط كاملة، بدون فرق بين الأول والأخير.
3. **اللعب الفردي**: تلعب لحالك مع عداد وقت لكل سؤال، بدون حاجة لإنترنت.
4. **مجموعة عبر الإنترنت**: نفس فكرة ١ و٢، لكن مفتوحة لأي شخص عن بعد عن طريق
   كود الغرفة.

## حالة المشروع الحالية

- ✅ **الوضع الفردي**: يعمل بالكامل بدون أي إعداد إضافي.
- ✅ **أوضاع اللعب الجماعي (١، ٢، ٤)**: تعمل — المشروع متصل بمشروع Firebase
  حقيقي. ⚠️ لكن باقية عليك خطوة أمان يدوية بسيطة، شاهد [FIREBASE_SETUP.md](FIREBASE_SETUP.md).

## البنية التقنية

- **الواجهة**: Flutter (يدعم أندرويد، و iOS، والويب لاحقاً بدون تعديل جوهري).
- **المزامنة الجماعية**: Firebase Firestore، بدون Cloud Functions — جهاز
  المضيف هو المسؤول عن حساب النقاط وإغلاق كل سؤال، فيجب أن يبقى تطبيقه مفتوحاً
  طوال المسابقة.
- **بنك الأسئلة**: حالياً أسئلة عامة تجريبية في `lib/data/sample_questions.dart`
  (يمكن استبدالها أو توسيعها بسهولة).
